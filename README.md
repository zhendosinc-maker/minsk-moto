# MINSK Moto | Презентационный сайт модельного ряда

Официальная веб-презентация модельного ряда мототехники MINSK на основе каталога ООО «МотоВелоЗавод».

## Особенности
- Полный модельный ряд (Classic, Urban, Enduro, Adventure, Scooters).
- Технические характеристики, фильтрация по категориям и фотографии из официального буклета.
- Контакты, история и сведения о заводе.
- Адаптивный дизайн для мобильных устройств и десктопов.

## Развертывание на Cloudflare Pages
1. В дашборде Cloudflare перейдите в **Workers & Pages** -> **Pages** -> **Create application** -> **Connect to Git**.
2. Выберите репозиторий `zhendosinc-maker/minsk-moto`.
3. Нажмите **Save and Deploy**.
